# DSH-AUDIO-050：迁移到 DSH 0.2.2-rc.1 并首次公开发布

- Status: Open
- Date: 2026-11-09

插件的兼容基线从 DSH `0.2.1-rc.5` 升到当前 npm `latest` 的 `0.2.2-rc.1`，并第一次发布到 GitHub 和 npm。

## Goal

外部用户在一个全新的 DSH `0.2.2-rc.1` 环境里，用 `dsh plugin --profile web add dsh-native-audio` 一条命令装上插件，在 Models 页给一个 provider 打开“原生音频输入”后，模型能听到音频。

## Scope

In scope:
- 依赖、`engines.dsh`、测试夹具与上游契约。
- 公开前的仓库清理：本机路径、私有项目名、测试夹具和验收记录里的私有内容、第三方许可声明、英文 README、package 元数据。
- GitHub 公开仓库、npm 发布、全新环境验收。

Out of scope:
- 逐模型音频勾选、MCP tool result 音频、Chat Completions 请求级音频预算、Gemini route 并入 stock Google route。

- [bundle](../specs/bundle.md)

## Acceptance

- `pnpm run check`（typecheck、测试、build）与 `python3 scripts/verify_subsystem_pages.py` 通过。
- 已有配置的 DSH home 升级后，Models 页的开关状态保留，真实请求能听到 `read_audio` 的音频。
- 全新 DSH home 用官方命令从 npm 安装，真实请求能听到音频。
